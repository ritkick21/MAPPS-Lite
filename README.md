# MAPPS-Lite

MAPPS-Lite is a small AI-agent project for materials discovery. The goal is to search public materials data, rank candidate materials, and explain why certain materials may be promising.

The project is inspired by MAPPS-style scientific agents, where an AI system plans, uses tools, evaluates results, and revises its search strategy.

## Research Question

Can a lightweight AI agent rank battery cathode candidate materials using public materials data and explainable scoring rules?

## Week 1 Goal

- Set up the project repository
- Learn the MAPPS workflow
- Choose one materials domain
- Download or prepare a small materials dataset
- Build a first baseline scoring system
