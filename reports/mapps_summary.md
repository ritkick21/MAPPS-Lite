# MAPPS Workflow Summary

## What MAPPS Does

MAPPS is an AI-agent system for materials discovery. It combines planning, tool use, physics-based evaluation, and scientist feedback to search for promising crystal materials.

## Main Workflow

1. Planner: decides what scientific task to solve.
2. Scientist feedback: adds human guidance and constraints.
3. Tool/code generator: creates code to run calculations or searches.
4. Physics toolbox: evaluates materials using scientific tools.
5. Revision loop: uses results to improve the next search.

## Why This Matters

Materials discovery is difficult because there are many possible compounds. MAPPS-style systems help automate the search process while keeping the reasoning scientific and explainable.

## How MAPPS-Lite Will Be Different

MAPPS-Lite will be a smaller student version. Instead of doing full physics simulations, it will use public materials data and scoring rules to rank materials.
